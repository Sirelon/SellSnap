Threads agent — owner setup, part 1

Staging account, Meta app, Telegram bot. About 75 minutes. Written 2026-10-09 for THREADS-AGENT-DESIGN.md §11 and Linear SIR-140.

When you finish this page:

  • A private staging Instagram + Threads pair exists.
  • A Meta app has the staging profile as a Threads tester, and a test token works.
  • A Telegram bot exists. Its token and the Threads app secret are in Secret Manager.
  • You send me the non-secret values from step 10.

Why today: the brand accounts must wait at least 7 days after the staging account (D34). A staging account created on 2026-10-09 allows brand accounts on 2026-10-16.

Three rules for the whole page

  • Secrets never go into chat, email or notes. The bot token, the Threads app secret and any Threads access token go only into the Terminal commands on this page.
  • Use your phone on your home network. Do not use a VPN. New accounts that change network or device right away get flagged more often. Tip
  • Meta renames buttons often. If a label differs, pick the closest match and note what you saw in step 10.

2Staging Instagram account~10 min, phone

  • In the Instagram app, tap the Profile tab. Tap your username at the top. Tap Add Instagram account, then Create new account. Guide
  • Enter the username sellsnap.staging and the display name SellSnap Staging.
  • When Instagram offers Accounts Center, tap Create password instead of Allow and continue. This keeps the test account out of your personal Accounts Center. Guide Tip
  • Add the staging email, confirm the code, and tap Complete sign-up. Save the password.
  • Make the account private: ☰ → Account privacy → turn on Private account.
  • Keep the account type Personal. Do not switch to Creator or Business: a professional account cannot be private. Guide
  • Set the bio to Private test account. A profile photo is optional.
  • Turn on two-factor authentication: ☰ → Accounts Center → Password and security → Two-factor authentication → pick the account → Authentication app. Then save the codes from Additional methods → Backup codes. Guide
  • Do not follow anyone, post, or send messages from this account. Tip

3Staging Threads profile~5 min, phone

  • Open the Threads app. If it shows your personal profile, open Profile → tap your username → Add profile. On a fresh install, tap Log in with Instagram. Guide
  • Log in with sellsnap.staging. Import the name and bio from Instagram.
  • When Threads asks about privacy, choose Private profile. Then tap Join Threads.
  • Check that it is private: Profile → ☰ → Settings → Privacy → Private profile is on. Threads privacy is set apart from Instagram privacy. Guide
  • Optional: from your personal Threads profile, request to follow sellsnap.staging, and approve it there. Then you see the test posts in your own feed.

Threads also allows sign-up without Instagram in some regions. Use the Instagram path anyway. The design plans an Instagram + Threads pair per account, and Meta's docs do not confirm that a standalone profile can be a Threads tester. Tip

6Permissions and settings~10 min, Mac

Permissions

  • Left menu Use cases → Access the Threads API → Customize (pencil icon) → Permissions. Meta docs
  • Click Add next to each of these 7 permissions. threads_basic is already there and cannot be removed. Meta docs

Add all 7 now, including the two for Phase 4. A token carries only the permissions that existed when the account authorized the app. A permission added later forces a new authorization on every account.

  • Put the placeholder https://sirelon.github.io/SellSnap/ into Client OAuth Settings (valid OAuth redirect URIs), Deauthorize callback URL and Data Deletion Requests URL. Click Save. Meta docs

App settings for App Review

8Test a token~5 min, Mac

This step proves that steps 5–7 work today, not on deploy day. It also answers an open item in the design (§9): where the dashboard token comes from, and how long it lives.

  • Use cases → Access the Threads API → Customize → Settings. Scroll to the bottom, to the token generator. Click Generate access token next to sellsnap.staging. Log in as staging and approve every permission. Copy the token. It starts with TH. Guide
  • If the settings page has no generator: Tools → Graph API Explorer → switch the host dropdown from facebook to threads.net → check that Meta App is SellSnap Agent → Generate Threads Access Token. Guide
  • Run this in the Terminal. The commands on this page use zsh, the macOS default. read -s hides what you paste, so the token stays out of your shell history.
read -s "TH_TOKEN?Threads token: "; echo
curl -s "https://graph.threads.net/v1.0/me?fields=id,username&access_token=$TH_TOKEN" | jq
curl -s "https://graph.threads.net/v1.0/debug_token?input_token=$TH_TOKEN&access_token=$TH_TOKEN" \
  | jq -c '.data | {is_valid, scopes,
      token_days: ((((.expires_at // 0) - now) / 86400) | floor),
      grant_days: ((((.data_access_expires_at // 0) - now) / 86400) | floor)}'
unset TH_TOKEN

Expected

  • The first call prints "username": "sellsnap.staging".
  • The second prints one line with "is_valid":true and 8 scopes. token_days is 0 for a 1-hour token or about 59 for a 60-day token. Copy that line into step 10.

If it fails

  • "The user has not accepted the invite to test the app" — finish step 7. Guide
  • Error code 190 — the token is wrong or expired. Generate a new one.
  • Fewer than 8 scopes — a permission in step 6 did not save. Add it, then generate a new token.
  • Do not keep the token. On deploy day you generate a fresh one and send it to the bot with /token staging.

9Telegram bot~5 min, phone or Mac

  • In Telegram, open @BotFather (it has a blue check mark). Send /newbot.
  • Name: SellSnap Agent. Username: sellsnap_agent_bot. A username has 5–32 Latin letters, digits or underscores, ends in bot, and cannot change later.
  • BotFather replies with the token. It looks like 110201543:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw. Leave the message there for step 10.
  • Send /setjoingroups, pick the bot, choose Disable. The bot works only in your private chat.
  • Optional: /setuserpic with the app icon.
  • Skip /setcommands. The service registers its commands when it starts.
  • Open your bot (t.me/sellsnap_agent_bot) and tap Start. Step 10 reads your user id from that message.

10Store secrets, send me the values~5 min, Mac

Telegram token and your user id

read -s "TG_TOKEN?Bot token: "; echo
curl -s "https://api.telegram.org/bot$TG_TOKEN/getUpdates" | jq -c '[.result[] | .message.from // empty | {id, username}] | unique'
printf %s "$TG_TOKEN" | gcloud secrets create TELEGRAM_BOT_TOKEN --data-file=- --replication-policy=automatic --project=sellsnap-6e85c
unset TG_TOKEN

The id number is your Telegram user id. An empty list means the bot has not seen your Start yet. getUpdates works only until the service sets its webhook on deploy day.

Threads app secret

Click Show next to Threads app secret (step 6), copy it, then run:

read -s "TH_SECRET?Threads app secret: "; echo
printf %s "$TH_SECRET" | gcloud secrets create THREADS_APP_SECRET --data-file=- --replication-policy=automatic --project=sellsnap-6e85c
unset TH_SECRET
gcloud secrets list --project=sellsnap-6e85c

Expected: the list shows OPENAI_KEY, TELEGRAM_BOT_TOKEN and THREADS_APP_SECRET. If a secret already exists, replace secrets create NAME --replication-policy=automatic with secrets versions add NAME.
